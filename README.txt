VOCAB – instalace na iPad a Android (GitHub Pages)
1. Na github.com si vytvoř účet a nový veřejný repozitář (např. vocab).
2. Add file -> Upload files: nahraj VŠE z rozbalené složky (index.html, manifest.webmanifest, sw.js a složku icons).
3. Settings -> Pages -> Branch: main, složka /(root) -> Save.
4. Za minutu dvě se objeví adresa https://TVOJEJMENO.github.io/vocab/ – otevři ji online.
5. iPad (Safari): Sdílet -> Přidat na plochu.
   Sony Xperia (Chrome): menu ⋮ -> Instalovat aplikaci / Přidat na plochu.
6. Slovíčka jsou v každém zařízení zvlášť. Přenos: Záloha -> Stáhnout zálohu -> v druhém zařízení Importovat.
